Curve Lab

The elliptic-curve cryptography used by Bitcoin and Ethereum, implemented in plain JavaScript without crypto libraries: secp256k1 arithmetic, Keccak-256, ECDSA with public key recovery, Schnorr signatures (BIP-340) and Shamir secret sharing. Everything below runs in the browser.

1. Point addition on a small curve

The points of y² = x³ + 7 over a small prime field. Click two points to add them. Enter k and press the button to compute k × P step by step.

4. Nonce reuse attack

If the same nonce k is used to sign two different messages, the private key can be calculated from the two signatures: k = (z₁ − z₂) / (s₁ − s₂) and d = (s₁k − z₁) / r, all mod n. This is how the PlayStation 3 signing key was recovered in 2010.

Tests

Public keys and signatures are checked against OpenSSL (through Node's crypto module) in both directions, and against published Keccak-256, EIP-55 and BIP-340 test vectors. BigInt arithmetic is not constant-time, so this code is for learning, not for holding funds.
